# 上班鼓励器（Android）

实时显示“今日已赚”的安卓小工具，支持 Android 16 实时活动（Live Update，状态栏胶囊 / iQOO 原子岛）以及顶部悬浮“灵动岛”胶囊。

- 默认：江苏百得外包服务有限公司上海分公司，月薪 2740，周一至周五 8:30–17:30，午休 11:30–13:30 不计薪
- 日薪 = 月薪 / 21.75（法定月计薪天数），时薪 = 日薪 / 7 小时
- 全部可在 App 右上角“设置”中修改

安装：下载 `ShangBan.apk` 到手机安装。构建：`./build.sh`（需要 Android SDK platform 36 + build-tools 36.0.0）。
